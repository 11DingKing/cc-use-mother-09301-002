# 差异化评价指标库

本项目维护差异化评价指标库的领域约定、角色边界与样例数据，并提供一套完整的事件溯源后端：
按办学类型维护指标、权重、数据来源与生效区间；计算时封存口径与缺失证据；新口径必须多人会签；
已公布结果只能以更正版本处理；审计人员可复算任一年度，并看清迟到数据、撤销签署、并发发布分别改变了什么。

## 领域模型

- **参与者**（`domain/contract.json`）：评价管理人员、高校填报员、审计人员。
- **口径版本状态机**：草案 → 会签 → 生效 → 封存；封存版本永不原地修改，调整只能开立"更正"版本。
- **三大贡献维度**：技能人才培养、地方服务、基础研究。每套口径必须覆盖三个维度且权重之和为 1。

### 关键不变量

| 诉求 | 实现方式 |
| --- | --- |
| 一套指标无法衡量不同办学类型 | 口径按"办学类型 + 年度"区分，指标、权重、数据来源各自独立维护 |
| 指标调整导致历史排名漂移 | 口径封存后冻结（指标/权重/来源/生效时间不可改）；调整走更正版本，旧版本原样保留 |
| 计算时封存口径与缺失证据 | 公布事件内嵌按封存口径算出的逐行结果、口径指纹与输入指纹；无数据记 `NO_DATA`、有值无证据记 `NO_EVIDENCE` 均计 0 并随结果留痕 |
| 新口径必须多人会签 | 生效要求 ≥2 名互不相同的签署人（管理/审计角色）；会签期可由本人撤销签署，撤销后人数不足即无法生效 |
| 已公布结果只能更正 | 公布后填报被拒；须开立指向旧封存口径的更正口径（重新会签封存）与更正记录，原记录标记被替代但保留 |
| 审计可复算任一年度 | 全部状态来自追加事件日志，可按任意事件序号重建；`replay_year(year, as_of_seq)` 与公布快照逐行核对 |
| 看清迟到数据改变了什么 | 公布前重复填报被标记为迟到数据，窗口归因给出旧值/新值/总分差值；公布后迟到数据一律拒绝 |
| 看清撤销签署改变了什么 | 窗口归因给出撤销前后有效签署人与人数 |
| 看清并发发布改变了什么 | 乐观序号锁：同序号并发只有一个发布事件落日志，落败方不产生任何状态变更，审计可指出胜出序号与发布人 |

## 目录

- `domain/contract.json`：领域角色、状态、约束和样例。
- `src/domain_contract/`：契约读取与确定性校验。
- `src/assessment_backend/`：事件溯源后端。
  - `events.py` / `storage.py`：不可变事件、追加日志、乐观并发与 JSONL 持久化。
  - `models.py`：高校、口径版本、签署、考核记录、指标取值。
  - `projection.py`：事件折叠为状态、口径指纹、确定性计分。
  - `service.py`：命令处理、角色权限、会签工作流、封存与更正。
  - `audit.py`：年度复算、封存核对、变更窗口归因、并发发布核查。
- `tools/check_contract.py`：契约命令行摘要检查。
- `tools/demo.py`：端到端演示（差异化口径 → 会签/撤销 → 缺失证据 → 迟到数据 → 并发发布 → 更正 → 审计复算）。
- `tests/`：契约与后端回归测试（38 个用例）。

## 验证

```bash
# 全部测试（契约 + 后端）
python3 -m unittest discover -s tests -v

# 编译检查
python3 -m compileall -q src tools tests

# 契约摘要
python3 tools/check_contract.py domain/contract.json

# 端到端演示（事件日志写入 data/events.jsonl，可删除后重跑）
python3 tools/demo.py
```

## 设计说明

- **仅依赖 Python 3.11 标准库**，无 Web 框架；命令处理函数即应用边界，便于后续包一层 HTTP/RPC。
- 时间戳与 ID 通过 `SystemRuntime` / `FixedRuntime` 注入，演示与测试结果确定可复现。
- 事件日志是唯一事实来源（JSONL 每行一个事件）；任何时刻的状态都是事件的纯折叠结果，
  因此"任一时点复算"与"历史排名不漂移"由结构保证，而非靠约定。
